## 🔹 PARTE 1 — OS OPERADORES ARITMÉTICOS

São os símbolos que dizem **qual operação fazer**. A maioria você já conhece! Veja:

| Operação | Símbolo | Exemplo | Resultado |
|---|---|---|---|
| Adição | `+` | `5 + 2` | `7` |
| Subtração | `-` | `10 - 4` | `6` |
| Multiplicação | `*` | `3 * 4` | `12` |
| Divisão | `/` | `8 / 2` | `4` |
| **Resto da Divisão** | `%` | `7 % 2` | `1` |

### ⚠️ Atenção aos detalhes importantes:
- ❌ **Não se usa `×` nem `÷`** → sempre `*` e `/`
- ➗ **Divisão de inteiros**: se os dois números são inteiros, o resultado sai inteiro (perde a vírgula). Ex: `7 / 2 = 3` (não 3,5)
- 📍 **Resto da divisão (`%`)** → diz o que SOBRA quando divide. É MUITO útil! Ex: `7 % 2 = 1` → sobra 1. Serve para descobrir se número é par, se é múltiplo, etc.

## 🔹 PARTE 2 — EXPRESSÕES E ORDEM DE CÁLCULO

> **Expressão = combinação de números, variáveis e operadores.** O computador segue uma **ordem de prioridade** para calcular.

### 📌 Regra de Prioridade (o que calcula PRIMEIRO):
1. 🥇 **Parênteses `( )`** → de dentro para fora
2. 🥈 **Multiplicação `*`, Divisão `/`, Resto `%`** → da esquerda para a direita
3. 🥉 **Adição `+` e Subtração `-`** → por último, da esquerda para a direita

### Exemplos passo a passo:

```
📌 Exemplo 1:  2 + 3 * 4
               ↓
            3 * 4 = 12
               ↓
            2 + 12 = 14
👉 Resultado = 14  (não é 20! Multiplicação vem antes)
```

```
📌 Exemplo 2:  (2 + 3) * 4
                ↓
               5 * 4 = 20
👉 Resultado = 20  (parênteses muda tudo!)
```

```
📌 Exemplo 3:  10 - 8 / 2 + 3
                 ↓
               8 / 2 = 4
                 ↓
            10 - 4 + 3 = 9
👉 Resultado = 9
```

```
📌 Exemplo 4:  7 % 2 + 4 * 3
                 ↓      ↓
                1   +   12 = 13
👉 Resultado = 13
```

> 💡 **Dica de Ouro:** Se tiver dúvida sobre a ordem, **coloque parênteses**! Fica mais claro e garante que calcula do jeito que você quer.

## 🔹 PARTE 3 — USANDO COM VARIÁVEIS

Aqui é onde fica PODEROSO! Você guarda valores em variáveis e calcula com elas:

```portugol
inteiro a = 10
inteiro b = 3

inteiro soma = a + b          // 10 + 3 = 13
inteiro mult = a * b          // 10 * 3 = 30
inteiro resto = a % b         // 10 dividido por 3 = 3 e SOBRA 1 → resto = 1

real preco = 50.0
real desconto = 10.5
real total = preco - desconto  // 50.0 - 10.5 = 39.5
```

### ✅ Exemplo Completo — Cálculo de Média
```portugol
// Declarar variáveis
real nota1, nota2, media

// Entrada de dados
escreva("Digite a primeira nota: ")
leia(nota1)
escreva("Digite a segunda nota: ")
leia(nota2)

// Cálculo (expressão!)
media = (nota1 + nota2) / 2

// Saída
escreva("A média é: ", media)
```

> ⚠️ Repare nos parênteses! `(nota1 + nota2) / 2` → soma PRIMEIRO, depois divide. Sem parênteses dividiria só a nota2 por 2 e somaria com nota1 → ERRADO!

## 🧠 RESUMÃO PARA NÃO ESQUECER

| Símbolo | Operação | Prioridade |
|---|---|---|
| `+` | Adição | 3ª |
| `-` | Subtração | 3ª |
| `*` | Multiplicação | 2ª |
| `/` | Divisão | 2ª |
| `%` | Resto da Divisão | 2ª |
| `( )` | Parênteses | 1ª — SEMPRE primeiro! |

> **Regra de ouro:** Parênteses → Mult/Div/Resto → Soma/Subt

### Exercício 1 — Calcule na cabeça
> Diga qual é o resultado de cada expressão. Depois confira!

| Expressão | Resultado |
|---|---|
| `4 + 5 * 2` | ? |
| `(4 + 5) * 2` | ? |
| `10 - 6 / 3` | ? |
| `(10 - 6) / 3` | ? |
| `8 % 3` | ? |

<details>
<summary>👀 Ver Respostas</summary>

- `4 + 5 * 2` → 4 + 10 = **14**
- `(4 + 5) * 2` → 9 * 2 = **18**
- `10 - 6 / 3` → 10 - 2 = **8**
- `(10 - 6) / 3` → 4 / 3 = **1** (divisão de inteiros!)
- `8 % 3` → 8 ÷ 3 = 2 e sobra 2 → **2**
</details>

### Exercício 2 — Cálculo de IMC
> Crie um programa que peça **peso** e **altura** do usuário e calcule o IMC.
> Fórmula: `IMC = peso ÷ (altura × altura)`

<details>
<summary>👀 Ver Resposta</summary>

```portugol
real peso, altura, imc

escreva("Digite seu peso em kg: ")
leia(peso)
escreva("Digite sua altura em metros: ")
leia(altura)

imc = peso / (altura * altura)

escreva("Seu IMC é: ", imc)
```
</details>

### Exercício 3 — Desafio 💪
> Crie um programa que peça um **número inteiro** e mostre:
> - O dobro dele
> - A metade dele
> - O resto da divisão dele por 5

<details>
<summary>👀 Ver Resposta</summary>

```portugol
inteiro num
real dobro, metade, resto

escreva("Digite um número: ")
leia(num)

dobro = num * 2
metade = num / 2.0       // dividindo por 2.0 (real) → não perde vírgula
resto = num % 5

escreva("Dobro: ", dobro)
escreva("Metade: ", metade)
escreva("Resto por 5: ", resto)
```
</details>
