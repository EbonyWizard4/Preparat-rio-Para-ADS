## 🔹 PARTE 1 — O QUE É PROGRAMAÇÃO?

### 💡 Conceito Simples
> **Programação = dar instruções claras e sequenciais para o computador executar.**

O computador é como uma máquina muito obediente mas **sem imaginação**: ele faz EXATAMENTE o que você mandou, do jeito que mandou. Se você esquecer um passo ou mandar errado → dá erro! 🤖

### Analogia Perfeita 🍳
Programar é **como escrever uma receita**:
- Você diz **o que fazer** → passo a passo
- Diz **em qual ordem** → não pode misturar os passos
- Define **quais ingredientes** vai usar
- Qualquer pessoa (ou computador) que siga à risca → chega ao mesmo resultado

### Para que serve?
- Resolver problemas de forma automática
- Fazer tarefas repetitivas sem cansar
- Criar ferramentas, sistemas, jogos, aplicativos

## 🔹 PARTE 2 — O QUE É UM ALGORITMO?

> **Algoritmo = sequência ordenada, finita e clara de passos para resolver um problema.**

Não é coisa de outro mundo! Usamos algoritmos **todos os dias**:
- 🪥 Escovar os dentes
- ☕ Fazer café
- 🚶 Sair de casa e chegar à faculdade

### ✅ 4 Regras de Ouro de um Algoritmo:
1. **Clareza** → cada passo tem um só significado
2. **Ordem** → os passos estão na sequência certa
3. **Finitude** → tem um começo e um fim (não é infinito!)
4. **Entrada e Saída** → recebe dados → processa → entrega resultado

---

### 📝 Exemplo Real: Algoritmo "Fazer um Café"

```
INÍCIO
  1. Pegar a chaleira
  2. Colocar água na chaleira
  3. Ligar o fogo
  4. Esperar a água ferver
  5. Pegar o pó de café
  6. Colocar o pó no coador
  7. Despejar a água quente sobre o pó
  8. Esperar o café escorrer
  9. Servir na xícara
FIM
```

> Veja: se trocasse o passo 4 e o 7 — despejasse a água fria primeiro — não daria certo! **A ordem é tudo.**

## 🔹 PARTE 3 — FLUXOGRAMA (Desenhando o Algoritmo)

> **Fluxograma = desenho visual do algoritmo.** Usa formas geométricas padrão para representar cada passo. Fica fácil de entender!

### 📐 Símbolos Oficiais que Você Precisa Saber:

| Símbolo | Nome | Para que serve |
|---|---|---|
| ⭕ Retângulo arredondado | **Início / Fim** | Marca onde começa e onde termina |
| ▭ Retângulo | **Processo** | Ação, cálculo, passo a executar |
| 📦 Paralelogramo | **Entrada / Saída** | Receber dados ou mostrar informação |
| 💎 Losango | **Decisão** | Pergunta com resposta SIM ou NÃO |
| ↗️ Seta | **Linha de fluxo** | Indica a ordem dos passos |

---

### 📊 Exemplo de Fluxograma na Prática — "Verificar se pessoa é maior de idade"

```
        ⭕ INÍCIO
          ↓
    📦 Ler idade
          ↓
    💎 Idade ≥ 18?
       /       \
    SIM        NÃO
      ↓         ↓
▭ Mostrar    ▭ Mostrar
"É maior"   "É menor"
          \   /
            ↓
         ⭕ FIM
```

> O losango SEMPRE tem 2 caminhos: **SIM** ou **NÃO**. É aqui que o algoritmo toma decisões!

## 🧠 RESUMÃO PARA NÃO ESQUECER

| Conceito | Explicação em uma frase |
|---|---|
| Programação | Instruções claras para o computador |
| Algoritmo | Sequência de passos para resolver um problema |
| Fluxograma | Desenho visual do algoritmo com símbolos padrão |
| Ordem | Os passos devem estar na sequência correta |
| Decisão | Quando o algoritmo escolhe um de dois caminhos (SIM/NÃO) |

### Exercício 3 — Desenhe o Fluxograma 💪
> Desenhe com os símbolos aprendidos o fluxograma de: **"Verificar se um número é par"**
> - Entrada: um número
> - Regra: se o número dividido por 2 sobra 0 → é par
> - Saída: "É par" ou "É ímpar"

<details>
<summary>👀 Ver Resposta</summary>

```
        ⭕ INÍCIO
          ↓
    📦 Ler número
          ↓
    💎 Resto da divisão
       por 2 é igual a 0?
       /               \
    SIM                NÃO
      ↓                 ↓
▭ "É PAR"         ▭ "É ÍMPAR"
          \           /
            ↓
         ⭕ FIM
```
</details>
